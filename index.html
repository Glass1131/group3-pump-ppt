열역학 제1법칙 (에너지 보존 법칙)

기체에 들어온 열은 온도를 올리는 데 쓰이거나 외부에 일을 하는 데 쓰입니다.

Q = ΔU + W

교과서 65쪽 · 기체가 흡수한 열(Q) = 내부 에너지 변화량(ΔU) + 외부에 한 일(W)

Q (열) 열의 출입

기체가 밖과 주고받는 열에너지입니다.
• 열 흡수: Q > 0
• 열 방출: Q < 0

ΔU (내부 에너지) 교과서 64쪽

공기 분자들이 바쁘게 움직이는 에너지입니다.
• 절대온도(T)에 비례 (U ∝ T)
• ΔU > 0 → 공기가 뜨거워짐!

W (기체의 일) W = PΔV

기체가 부피를 바꾸며 하는 일입니다.
• 팽창(ΔV > 0): 기체가 일함 (W > 0)
• 압축(ΔV < 0): 눌려서 일 받음 (W < 0)

💡 핵심 포인트: 펌프로 공기를 꾹 누르면 부피가 줄어들어 기체가 외부로부터 일을 받는다(W < 0)!

압축 속도에 따라 무엇이 달라질까?

공기를 빠르게 누를 때와 천천히 누를 때의 열역학 과정 비교

빠르게 압축할 때 단열 압축
Q ≈ 0  →  ΔU = -W > 0
  • ① 너무 빨라서 주위와 열을 주고받을 시간 없음 (Q ≈ 0)
  • ② 외부에서 꾹 눌러서 기체가 일을 받음 (W < 0)
  • ③ 받은 일이 전부 내부 에너지 증가로 전환됨
🔥 결과: 기체 온도 급상승! (펌프가 뜨거워짐)
아주 천천히 압축할 때 등온 압축
ΔU = 0  →  Q = W < 0
  • ① 천천히 누르면 주위와 열 교환할 시간 충분
  • ② 기체가 일을 받은 만큼 열이 밖으로 방출 (Q < 0)
  • ③ 내부 에너지 변화 없음 (ΔU = 0)
❄️ 결과: 기체 온도 일정 유지! (펌프 안 뜨거워짐)
